# RimTalk用 日本語Scribanテンプレート

ポーンの性格・関係・現在の状況に合った日本語会話を生成しやすくするテンプレートです。

## 導入方法

1. 新しいプロンプトプリセットを作成します。
2. `JSON Format`・`Chat History`・`Dialogue Prompt`をオフにします。
3. `Base Instruction`をBase Instruction.txtの全文で置き換え、ロールを`System`にします。
4. `Context`をContext.txtの全文で置き換え、ロールを`User`にします。
5. Rimtalkの設定を後述の画像に合わせます

### ペルソナで使える条件記法

以下の構文を使う事で、通常のペルソナ設定を拡張出来ます
使用の際は改行必須です、1行につき1個にしてください。

| 書き方 | 反映される場面 |
| --- | --- |
| `落ち着いた口調で話す` | 常時 |
| `{30%}イタズラが好き{END}` | 指定確率 |
| `{"マッファロー"}マッファローを撫でるのが好き{END}` | キーワードがあるとき |
| `{!}戦闘中は無口になる{END}` | 危険な状況 |
| `{UN}場面を丁寧に描写する{END}` | ユニークイベント発生時 |

## カスタマイズ

テンプレート冒頭には、変更できる設定と辞書をまとめています。各コメントを読み、必要な項目だけ編集してください。

- 表示する特性
- 除外・短縮する健康情報
- 作業内容の不要語や表記
- AIが知らない敵やMOD種族の説明
- 派閥名やトレーダー種別の表示名
- 欲求・天候・マップイベント・バイオームの表示確率
- ユニークイベントの対象キーワード・性別・年齢・発生確率・指示文

## 注意事項

- 正しくプロンプトを生成出来ているかは1度LLMに情報を送った後にプロンプト設定のプレビューを押すことで確認出来ます
- **プレビュー画面ではテキスト生成に乱数を使用する関係でぷるぷるします**
![プレビュー画面](images/preview.png)
- 辞書編集の際は別のテキストエディタで編集し、先頭から末尾まで全文を貼り付けることをおすすめします。
- エラー時はテンプレート本文がそのままプロンプトへ送られる場合があります。編集後はプレビューを確認してください。
- 会話の自然さや指示への従いやすさは、使用するAIモデルによって変わります。（Gemini 3.5 Flash LiteがRPD 500でおすすめ）
- マップの敵情報はマップ全体を集計するため、目の前の交戦相手の数とは一致しない場合があります。
- MODやRimTalkの設定によって、取得できる情報や名称が変わる場合があります。

## このテンプレートで変わること一覧

### 自然な台詞が生成されやすくなります

情報を取捨選択し、プロンプトを日本語に統一することでLLMが自然な日本語を出力します

### 独り言と会話を区別します

一人なら自然な独り言、二人以上なら発言がつながる会話を生成するよう促します。

### 立場や敵対関係を反映します

入植者・訪問者・囚人・奴隷・敵対勢力などを区別し、敵同士の会話が安易に友好的になるのを抑えます。

### 配偶者や家族関係を反映します

会話相手や作業対象に関係する人物関係を抜き出し、夫婦・家族としての会話に生かします。

### 子供らしい反応を強調します

12歳以下のポーンには、年齢相応の語彙・判断・感情反応を使うよう促します。

### 戦闘中の会話を緊迫させます

交戦中は平穏な日常会話を避け、攻撃・警戒・切迫感を優先します。

### 危険時や狩猟中のみ武器を伝えます

装備中の武器を会話へ反映しやすくし、通常時は逆に武器を話をさせません。

### 怪我や失血死の危険を反映します

最近の怪我、全身に付く健康状態、重い出血や死亡予測を伝えます。Tick制御により延々と古傷の話をすることがなくなります。

### 喧嘩中・喧嘩直後の空気を反映します

入植者同士の喧嘩を敵との戦闘と区別し、終了後も怒り・気まずさ・怪我の由来を会話へ反映します。

### 遺体を生きた人物と取り違えにくくします

運搬・解体中の対象が遺体なら、名前・種別・所属・敵味方を補足します。

```text
【作業内容】
ポーチを運搬中
作業対象の補足：ポーチという人間の遺体（プレイヤー陣営に敵対／所属派閥「モイクポ」）
```

人間・動物・メカノイド・異常存在のほか、MODで追加された人型種族にも対応します。

### 場所を分かりやすく整理します

室内・屋外・部屋名を整理し、35℃以上または－10℃以下のときだけ温度を表示します。軌道上では固定の外気温を省きます。

### 天気の話ばかりになるのを抑えます

快晴・雨などの頻出する天候は低確率で表示し、特殊な天候や危険な環境を優先します。

### マップイベントを反映します

太陽フレアやサイコドローンなどを伝え、対象性別があるイベントは該当するポーンだけに表示します。

### 周辺の状況を反映します

プレイヤー入植者の会話では、敵対勢力・トレーダーの種類・バイオームなどを必要に応じて伝えます。

### 過去の会話を参考にします

以前に生成された台詞を参考情報として使い、会話の雰囲気や話題をつなぎやすくします。

### 特定の場面を専用シーンとして描写できます

指定したキーワードが交流履歴や現在の作業に現れたとき、一人の場面を詳しく描写する「UN（ユニークシーン）」へ切り替えられます。

### 表示内容を好みに合わせて調整できます

表示する特性、不要な健康情報、派閥名、作業名、敵やトレーダーの説明、天候などの表示確率を変更できます。
